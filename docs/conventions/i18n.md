# Internationalization

- No hardcoded user-visible text. Use `t('...')` from `useI18n()` in templates and scripts.
- Locales: `src/i18n/locales/tr.json` (primary, default locale and fallback) and `src/i18n/locales/en.json`. Configuration is in `src/i18n/index.ts`.
- Every new key is added to **both** files in the same change. Keys are dot-separated and grouped by feature (`nets.createNet`, `operators.deleteOperatorConfirm`).
- Reuse existing keys, including `nav.*` for page titles and `common.*` for generic actions, before adding new ones.
- Interpolation uses named params: `t('nets.totalCount', { count: total })`.
- Errors from the API are i18n keys or raw messages. Display them with `translateError(message)` (exported from `src/i18n/index.ts`): it translates known keys and returns the message unchanged otherwise.
- Dates and numbers use the helpers in `src/lib/formatters.ts` with the current locale, not hand-written formats.
- Current drift: `tr.json` and `en.json` do not have identical key sets (`nav.inventory` and `operators.deleteOperator*` exist only in `tr.json`; `disaster.quickReportPrompt` only in `en.json`). When you touch a key family, bring both files in line.
